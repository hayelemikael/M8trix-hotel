# M8trix Hotels website

Live: https://hayelemikael.github.io/M8trix-hotel/ · Menu: https://hayelemikael.github.io/M8trix-hotel/menu.html

- `social.js` – phone, email, WhatsApp/Telegram, Google Maps, address and social media links (one place for both pages)
- `menu-data.js` – the menu, until the Google Sheet back office is connected
- `index.html` / `menu.html` – the two pages; settings are in the `CONFIG` block at the top of each script
- `img/` – photos (`img/sm/` holds 700 px copies for phones)

Moving to a custom domain later: change the address `https://hayelemikael.github.io/M8trix-hotel/` in index.html, menu.html, robots.txt and sitemap.xml.
